# Code / Quote

A small Flask app that shows a random programming quote whenever the page is
opened or refreshed.

## Run locally

1. Create and activate a virtual environment.
2. Install the dependency with `pip install -r requirements.txt`.
3. Start the app with `python app.py`.
4. Open <http://127.0.0.1:5000> in your browser.

Use the **Another thought** button or refresh the page to get another quote.
